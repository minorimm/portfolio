# MINYORIS Portfolio

静的なポートフォリオサイトです。`index.html` をブラウザで開くと確認できます。

## 作品画像の差し替え

`images/work-01.svg` から `images/work-06.svg` が作品画像です。ご自身の画像を同じファイル名で上書きするだけで差し替えられます。写真を使う場合は、`index.html` 内の拡張子を `.jpg` または `.webp` に変更してください。

作品を押したときの詳細画面にも、同じ画像が自動で表示されます。

詳細画面のメイン画像・サブ画像2枚は、`index.html` の各作品にある `data-gallery` で個別に指定できます。先頭がメイン画像、以降2つがサブ画像です。

## 連絡先の変更

`index.html` 内の `HELLO@MINYORIS.COM` と `mailto:hello@minyoris.com` をご自身のメールアドレスへ変更してください。
